# 数据说明

数据文件 `UserBehavior_2025.csv`（6.9 MB）已经在仓库根目录，clone 下来可以直接跑。

## 字段

| 字段 | 说明 |
|---|---|
| 用户ID | 脱敏后的用户编号 |
| 商品ID | 商品编号 |
| 品牌 / 品牌ID | 商品品牌 |
| 商品名称 | 商品全称，含规格 |
| 商品类别 | 共 6 类：电子产品、家用电器、美妆护肤、家居用品、服装鞋帽、食品饮料 |
| 商品类目ID | 类目编号 |
| 行为类型 | `pv`（浏览）、`fav`（收藏）、`buy`（购买） |
| 时间戳 | Unix 秒，UTC |
| 售价 | 该条记录对应商品的价格（元） |

## 数据量

69,555 行，时间跨 2024-12-31 到 2025-12-31，约一年。

导入后可以直接跑 `analysis.py`，脚本第一步会打印行列数、缺失值、重复行，可以先核对。
